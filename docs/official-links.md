## 五、关于注册资本的限制性证据

以下材料可以作为“注册资本并非完全没有约束”的反向证据，但不能据此推导出学生公司必须达到某个统一金额：

| 限制类型 | 近年官方依据 | 对学生创业公司的意义 |
|---|---|---|
| 出资期限受限 | [《公司登记管理实施办法》](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2024/art_6580c00811be45bfa304c1273b74e294.html)，2025年2月10日起施行 | 普通有限责任公司股东认缴出资原则上应在成立之日起五年内缴足 |
| 注册资本和期限不得明显异常 | [市场监管总局注册资本登记说明](https://www.samr.gov.cn/djzcj/gzdt/art/2024/art_3e01fb8c9819474d86c7f8efcb69a6a4.html) | 不能为了显得“实力强”而填写明显超过实际能力的金额或期限 |
| 特殊行业可以有最低资本/实缴要求 | [《中华人民共和国公司法》](https://www.samr.gov.cn/djzcj/zcfg/fl/art/2026/art_9b4263a169cf43c2aba950cfc9ac1af2.html) | 法律、行政法规和国务院决定可以对特定行业另行规定 |
| 劳务派遣等业务存在实缴门槛 | [官方劳务派遣许可材料说明](https://rsj.baoji.gov.cn/col9976/col1294/202405/P020241228629579687817.pdf) | 如果经营范围涉及劳务派遣，需另行核对实缴资本和许可条件 |
| 融资担保等高风险行业有明确最低资本 | [《融资担保公司监督管理条例》](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_1cbe7e1113304562922f32e9f118aa35.html) | 融资担保公司注册资本不低于2000万元且为实缴货币资本；与普通学生公司无关 |

### 如何理解

1. “普通有限责任公司没有统一最低注册资本”仍然成立；
2. “注册资本可以随便写、永远不用缴、所有行业都一样”不成立；
3. 目前没有证据表明沧州交通学院对学生公司统一要求某个注册资本金额；
4. 商务服务、内容运营、普通文创和3D打印方向，暂未发现适用上述特殊行业资本门槛，但正式经营范围仍需向登记机关核对。

此前“有限责任公司最低注册资本三万元”的旧页面属于旧法口径，不能作为2024年7月1日后新设普通有限责任公司的现行依据。

## 六、线下核验时怎么问

到沧州具体登记窗口或通过官方电话咨询时，直接问以下五句话：

1. “学生拟在沧州交通学院大学生创业园登记个体工商户，经营场所是实验楼 A【具体房间】，应该到哪个县区登记机关办理？”
2. “学校提供盖章的场地使用协议和管理权说明，是否可以作为经营场所合法使用证明？”
3. “是否必须附学校产权证或不动产权属材料复印件？”
4. “是否接受无偿使用证明或经营场所申报承诺？”
5. “这个经营范围是否还需要其他行政许可或备案？”

咨询时应记录日期、部门、窗口、工作人员告知内容和需要补正的材料；能取得书面答复或业务咨询记录更好。
