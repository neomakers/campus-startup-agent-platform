# 河北省学生个体工商户落地计划

## 目标

围绕河北省内高校，完成一条可执行、可留证的链条：

学生提出申请 → 学校确认身份和创业事项 → 学校确认场地/地址支持 → 取得合法经营场所证明 → 向河北省属地登记机关申请个体工商户设立登记 → 领取营业执照 → 完成税务、收款和年度报告等基础运营事项。

本文以“学生本人登记为个体工商户”为对象，不把个体工商户误称为学生公司。个体工商户的登记事项包括经营者、住所、经营场所和经营范围；本试点只采用学生个人经营形式。依据：[个体工商户登记管理规定](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2025/art_521d2635c33c4a439f638905ed92056c.html)。

## 重要前提

### 1. 个体工商户不是多人股权公司

个体工商户登记的核心经营者是一个自然人；如果团队需要多名学生按股权共同持有、长期传承和明确投资关系，后续可能需要比较有限责任公司、合伙企业等形式。个体工商户更适合先验证个人产品、个人服务、网店或小规模经营。

### 2. 学校审批和工商登记是两件事

学校负责学生身份、项目/创业实践、校内资源和场地管理；河北省登记机关负责个体工商户设立登记。学校同意入驻，不等于已经取得营业执照；登记机关发照，也不等于学校允许在校内经营。

### 3. 以河北省登记地为主

个体工商户应向经营场所所在地登记机关申请设立登记。河北省公开材料显示，个体工商户登记职能通常由县级行政审批部门或市场监管部门承担，并可由乡镇、街道受委托办理。依据：[河北省市场监督管理局答复](https://scjg.hebei.gov.cn/guestbook/searchOne?guestbookId=4228)。

## 阶段一：确认试点学校和登记地

### 目标

先选定一个具体河北高校、一个具体校区、一个具体场地和一个具体县/区，避免一开始同时研究多所学校。

### 要确认的事项

- 学校名称和校区；
- 场地是校内教学/办公场所、创业园、大学科技园还是校外合作园区；
- 场地实际管理单位；
- 场地所在县/区；
- 计划经营内容是纯网络、产品制作、课程服务、商务服务还是混合经营；
- 是否涉及食品、教育培训、电子产品、宠物用品、印章等许可或特殊监管事项。

### 产出

形成《试点场地信息表》：学校、校区、地址、产权/管理单位、可使用面积、联系人、拟经营方式、登记机关和需要的证明材料。

## 阶段二：画出学校内部组织架构

### 首要协调部门

优先从以下部门中确认实际牵头部门，不预先假定每所学校都有相同组织名称：

1. 大学生创新创业中心/创新创业学院：通常负责创业项目、孵化基地和入驻审核；
2. 学生工作部门或就业创业指导部门：通常负责学生身份、创业实践和就业创业政策；
3. 学院：负责学生情况、学业影响、指导教师和学院意见；
4. 后勤、资产或大学科技园管理部门：负责场地、工位、租赁和房屋使用；
5. 保卫处/实验室管理部门：涉及设备、用电、消防、生产或实验时协调；
6. 科研、成果转化或知识产权部门：使用教师成果、学校设备或科研成果时协调；
7. 财务、税务或校办产业管理部门：涉及收费、合同、资产和对外经营时协调。

### 第一轮只问 6 个问题

- 学生以个体工商户身份经营，校内是否允许？
- 学校是否提供经营场地，还是只能提供创业工位？
- 哪个部门可以出具或协助取得经营场所合法使用证明？
- 是否需要学院同意、指导教师意见或家长知情？
- 个体工商户能否申请入驻创业孵化基地？
- 营业执照办理后，需要向学校备案哪些信息？

### 产出

形成《学校部门联系人与职责表》，记录部门名称、联系人、电话/邮箱、需要提交的材料、办理顺序、是否需要盖章以及答复证据。

## 阶段三：准备学校申请包

建议不要以“我要办营业执照”作为唯一申请主题，而是提交“学生创业实践与经营场地申请”，其中包含：

- 学生基本信息和学生证/学籍证明；
- 个体工商户拟经营者信息；
- 创业实践说明；
- 经营内容和拟用名称；
- 产品/服务说明；
- 经营范围初稿；
- 场地使用时间、面积和设备需求；
- 安全、消防、用电和卫生说明；
- 是否线上经营、是否接待客户、是否存放材料；
- 经营者对学业、税务、合同和安全责任的承诺；
- 指导教师或学院意见；
- 申请使用学校/园区地址作为经营场所的专项说明。

### 学校内部审批链（计划版）

学生/团队提出申请
→ 所在学院初审学生身份和学业影响
→ 创新创业中心审查创业实践和入驻条件
→ 场地管理部门确认场地和使用权限
→ 保卫/实验室/资产等相关部门确认安全和资源边界
→ 学校或园区管理单位决定是否同意入驻
→ 签订场地使用协议、入驻协议或安全责任书
→ 取得经营场所合法使用证明或明确不能用于工商登记

这里的“协议”不一定就是工商登记机关要求的租赁合同，必须进一步确认协议是否写明：出租/出借主体、房屋地址、面积、用途、使用期限、经营者、是否允许办理营业执照、是否允许转租或转借、双方签章。

## 阶段四：确认河北省经营场所材料

### 可能的材料路径

#### 路径 A：租赁协议 + 权属证明

河北省市场监管部门公开答复中列出的常见材料包括：租赁协议复印件，以及出租方房屋产权证或不动产权属证书复印件。

#### 路径 B：住所/经营场所申报承诺

河北省曾推行住所/经营场所申报登记制，申请人可以提交地址信息并对真实性、合法性和安全性作出书面承诺；但具体县区是否采用、哪些行业可以采用、是否仍需补充材料，必须向属地登记机关确认。

#### 路径 C：学校或园区托管地址

如果学校或园区提供的是集群登记、托管或集中办公地址，必须确认该地址是否允许个体工商户登记。国家 2025 年《个体工商户登记管理规定》明确，共享地址、不具备实际居住条件的集中办公区等集群登记场所，不得作为个体工商户经营者住所；同时，经营场所仍需提交合法使用证明。依据：[个体工商户登记管理规定第十至十三条](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2025/art_521d2635c33c4a439f638905ed92056c.html)。

#### 路径 D：仅网络经营场所

仅通过互联网开展经营活动的平台内经营者，可以按照规定使用电商平台提供的网络经营场所材料；但如果同时存在 3D 打印、仓储、线下交付、客户到访或产品制作，就不能简单按纯网络经营处理。依据：[河北省电子商务经营者登记问答](https://scjg.hebei.gov.cn/info/10375)。

### 场地核验清单

- 地址是否真实、固定、可联系；
- 出租/出借人是否有权提供使用；
- 房屋用途是否允许拟经营活动；
- 协议是否明确允许办理营业执照；
- 是否需要产权证、不动产权证或其他权属材料；
- 是否属于住宅、教学用房、实验室、宿舍或公共区域；
- 是否涉及消防、环保、食品、噪声、生产安全等限制；
- 经营者是否能在登记机关要求时提供原件或补充证明。

## 阶段五：向河北省属地登记机关申请

### 登记事项

个体工商户通常登记：

- 经营者姓名和住所；
- 组成形式：学生个人经营；
- 经营场所；
- 经营范围；
- 使用名称时的名称；
- 登记联络员信息。

### 基本材料

河北省官方答复列出的基本材料包括：

- 《个体工商户登记（备案）申请书》；
- 经营者身份证件；
- 经营场所使用相关文件；
- 经营范围涉及前置批准项目时的批准文件或许可证件；

依据：[河北省市场监督管理局个体工商户登记答复](https://scjg.hebei.gov.cn/guestbook/searchOne?guestbookId=4228)。

### 办理链

确定经营场所所在地
→ 确认县/区登记机关
→ 名称自主申报（如使用名称）
→ 填写个体工商户设立登记申请
→ 上传或提交身份证明和经营场所材料
→ 完成实名确认
→ 登记机关形式审查/地址核验
→ 补正或通过
→ 领取纸质或电子营业执照。

## 阶段六：领照后必须完成的基础事项

- 税务信息确认和申报方式确认；
- 收款账户和支付工具；
- 需要时办理发票；
- 按规定进行年度报告；
- 保存租赁/场地协议、采购、销售和售后记录；
- 经营范围发生变化时及时办理变更；
- 经营场所变化时及时办理变更；
- 与学校的入驻协议、学校备案和工商登记信息保持一致。

## 证据留存方案

每个节点至少保存：

1. 原始政策或学校通知的网页/PDF；
2. 访问日期；
3. 联系部门和联系人；
4. 咨询问题原文；
5. 对方答复原文或截图；
6. 提交材料清单；
7. 协议和证明材料版本；
8. 补正通知、受理回执和营业执照；
9. 实际耗时、费用、失败原因和修正动作。

## 下一步执行顺序

### 第一步：确定试点高校

当前计划以河北省内高校为主。需要先确定具体学校和校区；如果暂未确定，优先选择公开发布过创业孵化基地入驻通知、申请表或学生企业案例的高校。

### 第二步：取得学校内部流程图

先联系创新创业中心，再由其确认应协调的学院、学生工作部门、场地管理部门和园区运营主体，不直接在多个部门之间盲目递交材料。

### 第三步：取得场地书面答复

必须让学校明确回答“该场地能否用于个体工商户经营场所登记”，并确认学校能提供的是租赁协议、无偿使用证明、住所使用证明、托管协议还是仅限校内办公的入驻协议。

### 第四步：到属地登记机关做预审咨询

携带拟用场地协议样本、产权/管理证明样本、经营范围初稿和经营者身份证信息，向县/区登记机关确认材料是否可接受。

### 第五步：正式登记并建立样板档案

以一个学生、一个经营场所、一个低风险经营范围做首个样板，完整保存从学校申请到领取营业执照的所有证据，再决定是否扩展到更多学生和产品线。

## 当前不能擅自确定的事项

- 哪所高校一定允许学生在校内登记个体工商户；
- 哪个学校部门拥有最终审批权；
- 学校是否提供可用于工商登记的场地；
- 具体县区是否接受申报承诺制；
- 个体工商户是否适合多人长期合作；
- 3D 打印、宠物用品、课程和商务服务是否涉及额外许可或监管要求。
