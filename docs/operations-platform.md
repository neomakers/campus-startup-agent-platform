# 运营中台

## 为什么需要中台

无论未来销售 3D 打印产品、宠物用品、课程还是其他产品，底层都需要相似的运营能力。将这些能力统一沉淀，可以避免每条业务线重复搭建和重复犯错。

## 当前能力范围

- 视频选题、拍摄、剪辑和生产；
- 多平台发布、账号管理和内容复用；
- 用户线索收集、分级与跟进；
- 客户管理和 CRM 思路；
- 咨询、报价、成交和售后；
- 私域承接；
- 数据记录、分析和复盘；
- 自动化运营与 Agent 辅助运营；
- 从实践中沉淀课程内容。

## 第一阶段验证重点

先选择少量产品和平台，跑通“内容生产 → 分发 → 流量 → 咨询 → 成交 → 售后 → 数据复盘”。阶段初期重点是形成稳定流程和真实数据，不是同时覆盖所有平台或建设完整系统。

平台的具体工具、渠道、指标、人员分工和隐私/合规规则待讨论。
