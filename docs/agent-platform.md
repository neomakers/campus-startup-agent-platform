# Agent 平台

## 基本关系

平台不是试图让 AI 代替所有真人动作，而是把工作拆成三类：

1. **Agent 可辅助部分**：信息整理、材料草拟、清单生成、流程解释、状态汇总、风险提示、下一步建议和运营分析。
2. **API/系统可连接部分**：在权限、合规和接口条件允许时，连接账号、数据、通知或业务系统。
3. **真人必须执行部分**：身份与主体确认、注册及认证、场地和机构沟通、银行税务、签约审批、客户沟通、内容拍摄、交付和承担责任。

## 工作原则

- Agent 给出建议和提醒，不伪装成已经完成的真实动作。
- 每个流程应能看到当前状态、下一步、所需材料、负责人、截止时间和风险。
- 关键外部动作必须由有权限的真人确认并留下记录。
- 先从高频、重复、容易遗漏的流程做小规模验证，再决定是否产品化。
- Agent 的有效性以真实流程结果和复盘证据判断，而不是以对话体验判断。

## 可能的沉淀形式

- 流程 SOP 与检查清单；
- Agent 提示词、任务模板和状态模型；
- 在可行时使用的 API 连接；
- 材料模板与示例；
- 异常案例、风险说明和复盘记录。

具体技术选型、系统边界、数据存储方式和自动化程度均待验证。
