# 商业模式与业务线

## 总体模式

项目当前设想以一个长期存在的商务/创业服务主体为基础，以真实产品实验产生业务数据，以运营中台沉淀共同能力，以项目驱动型课程形成知识产品。各业务线先通过小规模实践验证，不预设最终规模和收入结构。

## 业务线

### 1. 商务/创业服务主体

第一家公司计划作为长期存在的商务服务/创业服务主体，也是整个系统的第一个真实实验对象。具体服务范围、收费方式、客户对象和合规边界仍需验证。

### 2. 真实产品实验

通过 3D 打印、小礼品、个性化签名章/艺术章等非公章产品、办公小物、情绪价值类手办、DIY 台灯、简单电子硬件和宠物用品等方向，验证真实商业闭环。它们是实验场，不等同于项目最终核心产品。

### 3. 运营中台

沉淀视频生产、内容分发、账号管理、内容复用、线索管理、CRM、销售转化、私域承接、数据分析、自动化运营和 Agent 辅助运营等共用能力。

### 4. 项目驱动型课程

课程方向可包括 Python、AI、Agent、机器人、ROS、3D 打印等。课程原则上从真实项目实践中产生，采取“边做项目、边沉淀、边做课程、边验证销售”的方式。

## 当前不做的承诺

目前不承诺固定收入、固定客户规模、固定课程产品、固定公司数量或完整自动化。所有尚未由实践验证的内容都应保留为假设。
