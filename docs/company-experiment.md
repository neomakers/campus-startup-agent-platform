# 公司实验

## 为什么要真实注册和运营公司

如果只做模拟项目，无法充分暴露企业账号、支付、银行、税务、合同、审批、客户和日常运营中的真实约束。因此，真实公司既是业务主体，也是 Agent 和 SOP 的第一个实验对象。

## 第一家公司

第一家公司计划定位为长期存在的商务服务/创业服务主体，负责承载早期流程验证和部分实际运营。原则上不因一届学生毕业而注销，未来可通过人员、负责人和必要的股权调整实现学生团队的代际传承。

学生既是平台运营者，也是平台最早的一批真实用户。

## 初步公司结构判断

- 一家长期存在的商务/创业服务公司；
- 一家科技创意/产品实验性质的公司，未来可承载 3D 打印、硬件、宠物用品等项目；
- 暂不为每个项目单独成立公司；
- 宠物业务先作为项目线验证；
- 公章刻制暂不纳入当前业务范围；
- 个性化签名章、艺术章、文创章等可研究为普通产品，但必须关注与公章业务的合规边界。

以上是当前判断，不是已经完成的法律、财务或组织方案。

## 需要记录的实验过程

后续应记录企业注册、创业园场地和注册地址协调、企业账号开通、微信支付、云服务器、域名、企业服务账号、企业认证、银行、税务、合同、审批及日常运营中的实际步骤、耗时、材料、失败原因、费用和风险。
