# 开放问题

本文件只记录尚未确定的问题，不替团队做最终决定。每个问题后续可补充负责人、验证方式、结论和日期。

## 组织与公司

- 第一家公司最终注册地、主体类型、负责人和股权安排是什么？
- 第二家科技创意/产品实验公司何时有必要成立？触发条件是什么？
- 如何设计跨届传承、权限交接和责任边界？
- 商务/创业服务主体具体服务谁，哪些服务适合由学生团队承担？

## 合规与风险

- 业务涉及的工商、税务、银行、合同、支付、企业认证和数据合规要求是什么？
- 个性化签名章、艺术章、文创章与公章的合规边界如何落地到产品、宣传和流程？
- 学生参与经营时的劳动、报酬、知识产权、安全和责任安排是什么？

## 产品与市场

- 第一批实验产品选哪些，选择标准和停止标准是什么？
- 首批客户是校内学生、教师、社团、创业团队还是校外用户？
- 哪些渠道和内容形式最适合验证流量与成交？
- 产品成本、定价、交付、售后和最小可行订单如何定义？

## Agent 与运营

- 第一条优先数字化的真实流程是什么？
- 哪些环节只做 SOP，哪些环节值得做 Agent 或 API？
- 如何记录流程状态、负责人、证据和外部动作结果？
- 第一阶段采用哪些运营指标判断是否真的形成闭环？

## 课程与团队

- 第一门课程从哪个真实项目开始沉淀？目标学习者和交付形式是什么？
- 核心团队规模、角色分工、招募和退出机制如何设计？
- 如何在不盲目扩张的情况下，让更多学生逐步参与？
