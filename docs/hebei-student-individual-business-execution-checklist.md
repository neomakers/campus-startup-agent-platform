# 河北省学生个体工商户首个试点执行清单

## 使用说明

本清单用于完成第一个学生个体工商户样板，不代表任何学校的正式审批表。当前以河北省内高校为主，以河北经贸大学公开的创业孵化园申请流程作为学校侧参考样板；具体落地时必须替换为目标学校的正式要求。

## 总体申请链

学生经营者确定 → 学院确认学生身份和学业影响 → 创新创业中心/就业创业部门确认创业事项 → 场地管理部门确认场地 → 学校或园区出具经营场所合法使用材料 → 向经营场所所在地县/区登记机关预审 → 个体工商户名称和设立登记申报 → 实名确认与材料补正 → 领取营业执照 → 税务、收款、年度报告和学校备案。

## 第一阶段：确定一个样板经营者

必须确定：经营者姓名、学校/学院/年级和学籍状态、个人经营还是家庭经营、经营内容、是否有其他共同参与学生、是否需要线下制作/仓储/客户到访/交付、经营场所所在县区。

个体工商户不是多人股权公司。其他学生可以作为工作人员、合作方或通过合同参与，但不能简单把多人股权关系放进个体工商户登记。如果核心目标是多人共同持股和长期传承，应在登记前重新比较有限公司或合伙企业。

## 第二阶段：学校内部第一次联系

### 联系顺序

1. 所在学院辅导员或就业创业联系人；
2. 学校大学生创新创业中心或创新创业学院；
3. 创业孵化基地/大学科技园运营单位；
4. 后勤、资产或场地管理部门；
5. 涉及设备、生产、用电或客户到访时，再联系保卫处、实验室管理部门或相关职能部门。

### 第一次只提交一页说明

标题可写为“学生个体工商户创业实践及经营场地申请咨询”，内容包括学生信息、拟登记经营者、经营内容、场地需求、产品制作/仓储/客户接待情况，以及请求学校告知负责部门、申请表和办理顺序。

### 必须获得的书面答复

- 学校是否允许学生以个体工商户形式开展创业实践；
- 学校是否允许在校内或园区内经营；
- 哪个部门负责受理；
- 是否需要学院推荐、指导教师意见或家长知情；
- 是否可以提供租赁协议、场地使用协议或其他经营场所合法使用证明；
- 该材料是否明确允许办理个体工商户营业执照；
- 营业执照办理前后分别需要提交什么材料。

## 第三阶段：学校申请材料包

### 学生身份材料

- 学生证或学籍证明；
- 身份证；
- 学院意见或辅导员意见；
- 指导教师意见（如学校要求）；
- 家长知情/同意材料（如学校要求）。

### 经营材料

- 个体工商户名称备选；
- 经营范围初稿；
- 产品或服务说明；
- 经营计划；
- 预计投入、收入和成本；
- 设备、材料和用电需求；
- 线上、线下或线上线下结合说明。

### 风险和责任材料

- 不影响正常学习的承诺；
- 消防、用电和设备安全承诺；
- 客户、售后和合同责任说明；
- 知识产权归属说明；
- 学校设备和场地使用责任说明；
- 不使用学校名义进行未经授权宣传的承诺；
- 经营者承担税务、债务和违法责任的确认。

## 第四阶段：场地协议核验

协议中最好明确：甲方及其管理权限、学生经营者、场地准确地址和房间号、面积、使用期限、用途、是否允许办理营业执照、是否允许线上销售/产品制作/仓储/客户交付、费用、安全消防和设备责任、退出和地址变更责任，以及甲方能否提供产权或合法使用权材料。

不要把只有工位分配通知、创业基地入驻证明、学生社团证明、口头同意或没有具体地址和期限的文件，直接当作工商登记地址证明。

河北省公开答复中，租赁房屋通常需要租赁协议和出租方产权/不动产权属材料；部分情形可以适用住所/经营场所申报承诺制，但是否适用于具体县区和行业必须预审确认。[河北省市场监管局场地材料答复](https://scjg.hebei.gov.cn/guestbook/searchOne?guestbookId=3241)

## 第五阶段：向属地登记机关预审

携带经营者身份证、学校/园区场地协议样本、场地权属或管理证明样本、经营范围初稿、线上/线下经营说明和学校入驻材料，向经营场所所在地登记机关咨询：地址能否登记、接受何种场地证明、是否需要产权证、经营范围是否涉及许可、实名确认方式，以及应向县级行政审批部门、市场监管部门还是受委托乡镇/街道办理。

河北省公开事项清单将个体工商户登记注册列为县级事项，实施机关为县级市场监管部门或行政审批部门。[河北省市场监管系统政务服务事项清单](https://scjg.hebei.gov.cn/uploads/1/file/public/202506/20250604153211_oy4seom7f5.pdf)

## 第六阶段：正式申请个体工商户设立登记

基本材料通常包括：《个体工商户登记（备案）申请书》、经营者身份证件、经营场所合法使用证明、涉及前置批准事项时的批准文件或许可证、家庭经营时的家庭成员材料、名称申报信息和登记联络员信息。

办理节点：确定登记机关 → 名称申报 → 填写设立登记申请 → 上传/提交材料 → 实名确认 → 登记机关审查 → 补正（如有） → 领取营业执照。

个体工商户应向经营场所所在地登记机关申请设立登记；仅通过网络经营的，才可能适用网络经营场所登记规则。[个体工商户登记管理规定](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2025/art_521d2635c33c4a439f638905ed92056c.html)

## 第七阶段：领照后闭环

- 向学校提交营业执照复印件或扫描件；
- 按学校要求办理创业基地入驻或备案；
- 确认税务信息和申报义务；
- 建立收入、成本、订单、售后和合同记录；
- 按规定报送年度报告；
- 经营场所或经营范围变化时办理变更；
- 保存所有学校和登记机关的材料、回执和答复。

## 证据链文件夹

```text
01-学校联系记录/
02-学院意见/
03-创业中心申请/
04-场地协议与权属材料/
05-登记机关预审记录/
06-名称申报/
07-设立登记申请/
08-补正与受理回执/
09-营业执照/
10-税务与年度报告/
```

每份文件记录日期、来源、经办人、文件名称、版本、是否原件、下一步和证据链接。
