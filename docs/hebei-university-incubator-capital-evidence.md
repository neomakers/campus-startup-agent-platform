# 河北高校创业园企业与实缴资本证据

> 核查时间：2026年9月3日。本文所称“最近一年”暂按 2025年9月3日至2026年9月3日理解。
>
> 本文只记录公开可核验的信息，不把“注册资本/认缴资本”写成“已经实际缴纳的资本”。“实缴 0 元”仅在公示信息明确写出 0 时使用；查不到实缴信息则写“未披露”，不推定为 0。

## 一、先给结论

1. 河北高校公开材料中的创业园主体，主要呈现为三类：学生创业团队、已登记企业、学校或学校资产公司参与设立的服务型企业。
2. 高校官网通常公开入园通知、项目名单、扶持内容和企业名单，但通常不公开每家学生企业的认缴与实缴明细。
3. 目前找到的、能由高校官网直接核实“认缴额 + 实缴额”的样本，是河北科技大学校属的河北科大众创科技有限公司：认缴 300 万元，公示实缴 0 元。
4. 这说明高校创业载体中确实存在“注册资本不等于已投入现金”的情况，但不能据此得出所有学生公司都应当实缴 0 元，也不能据此制定沧州交通学院的统一金额。

## 二、可直接核验的实缴样本

### 1. 河北科技大学：河北科大众创科技有限公司

学校创新创业中心于 2025年10月28日公开发布该公司的信用信息公示。公示显示：

| 项目 | 公示内容 |
|---|---|
| 企业名称 | 河北科大众创科技有限公司 |
| 统一社会信用代码 | 91130108MA7CLP9F3R |
| 登记地址 | 河北省石家庄市裕华区裕翔街26号河北科技大学校内工程中心J14室 |
| 企业状态 | 开业 |
| 控股性质 | 国有控股 |
| 股东 | 河北科大资产经营有限公司 |
| 认缴出资 | 300万元，货币 |
| 认缴出资期限 | 2051年11月25日 |
| 实缴出资 | 0万元 |
| 实缴出资时间 | 2021年11月26日（公示表列示日期） |

这是一条非常有价值的反向证据：企业注册资本可以较高，但在公示时实缴出资仍为 0。它同时提醒我们，阅读企业登记信息时必须把“认缴”“实缴”“出资期限”分成三个字段。

证据：

- [河北科技大学创新创业中心：河北科大众创科技有限公司信用信息公示（2025-10-28）](https://cxcy.web.hebust.edu.cn/xwtz/tzgg/4142c0cba02a41488bc7d1977638872b.htm)

### 2. 河北科技大学创业园 2025—2026 年入驻项目

河北科技大学于 2025年10月10日发布 2025 年众创空间（创业园）入驻申请通知，说明其创业园包括创业孵化园和牧星湖众创空间，可向入驻企业或团队提供办公场所/工位、创业指导、培训、政策咨询和商业对接。申请对象包括在读本硕学生项目团队，团队至少 3 人；已注册企业属于优先考虑条件之一，但不是所有项目必须先注册企业。

2025年11月7日，学校又公示了 2025—2026 年创业园入驻项目评审结果，但公示页面采用图片展示项目名单，未同步公开各项目的注册资本或实缴资本。

证据：

- [河北科技大学：关于2025年申请入驻大学生众创空间（创业园）项目的通知](https://cxcy.web.hebust.edu.cn/xwtz/tzgg/def4d4a32b87482588f7c613c3d42d6e.htm)
- [河北科技大学：2025年创业园入驻项目清单公示](https://cxcy.web.hebust.edu.cn/xwtz/tzgg/77c36973aebf48a69dc7b51303fa0d35.htm)

### 3. 河北建筑工程学院：2025年大学生众创空间项目

学校 2025 年通知明确：负责人可以是教师、在校生或毕业五年内学生；项目实行自筹资金、自主经营、自负盈亏；学校可协助项目调研、企业注册、营业执照办理、银行开户和税务登记。申请材料允许学院统一报送，也允许教师或学生个人报送；通过资格审查、可行性初审、答辩和公示后签订入驻协议，学校“协助部分项目申办注册企业”。

这是一条“学校可以协助注册、但不等于所有入园项目已经注册”的证据。该通知没有公布企业注册资本或实缴资本，因此不能用来推导金额。

证据：

- [河北建筑工程学院：关于开展2025年大学生众创空间项目入园申报通知（2025-11-14）](https://xsgzc.hebiace.edu.cn/info/1043/3034.htm)

## 三、河北工业大学创新研究院（石家庄）样本

河北工业大学创新研究院（石家庄）官网公开列出 7 家“已孵化企业”：

- 眼神科技（石家庄）有限公司
- 析氢新能源科技（河北）有限公司
- 河北仁仪智能科技有限公司
- 石家庄格林能源科技有限公司
- 石家庄维启生物科技有限公司
- 石家庄叠波智研科技有限公司
- 石家庄展领科技有限公司

这能证明该研究院采用“在研究院注册企业并进行孵化”的企业化模式，且企业方向偏人工智能、新能源、智能科技、生物科技等。但是该校官网页面没有列出这些企业的成立日期、认缴资本或实缴资本，因此本组只能作为“企业类型和孵化方式”参考，不能作为最近一年实缴资本样本。

证据：

- [河北工业大学创新研究院（石家庄）：企业孵化](https://chuangxin.hebut.edu.cn/cgzh/qyfh/index.htm)

## 四、这些案例对沧州交通学院有什么参考价值

可以参考的是结构，而不是直接照抄金额：

| 可参考内容 | 对沧州交通学院的启示 |
|---|---|
| 企业与团队并存 | 可以先允许学生以项目/团队申请，再决定个体工商户或公司登记形式 |
| 学校提供园区和服务 | 学校内部应明确场地、入驻、登记协助和后续备案分别由谁负责 |
| 注册企业不是所有项目的前置条件 | 注册业务可以作为独立流程，不必绑定大创、竞赛或指导教师 |
| 认缴和实缴分开管理 | 学生公司申请表应分别填写注册资本、认缴金额、出资期限和已实际投入金额 |
| 特殊行业另行核验 | 普通商务服务、内容运营、文创、3D打印不能套用劳务派遣等特殊行业的资本门槛 |

## 五、关于“实际缴了多少”的证据边界

### 已确认

- 河北科技大学公开样本明确列出：认缴 300 万元，实缴 0 万元。
- 河北科技大学、河北建筑工程学院公开材料都证明高校创业园可以容纳“企业”和“团队”，并提供不同程度的注册、场地或孵化支持。
- 河北工业大学创新研究院公开了已孵化企业名单，但没有公开资本缴纳明细。

### 尚未确认

- 河北高校 2025—2026 年全部入驻企业的完整名单。
- 每家学生企业的最新认缴金额、实缴金额和出资日期。
- 学校创业园是否要求企业必须有最低注册资本或最低实缴资本。
- 沧州交通学院大学生创业园是否允许学生以学校场地直接登记公司，以及学校能够出具哪一种场地证明。

## 六、后续逐家核验方法

对某个具体企业，建议按以下顺序留证：

1. 保存高校官网的入驻/孵化名单，证明“企业与该高校创业载体的关联”。
2. 取得企业名称、统一社会信用代码和登记机关。
3. 在[国家企业信用信息公示系统](https://www.gsxt.gov.cn/)查询基础登记和股东出资信息。
4. 同时记录认缴出资额、认缴期限、实缴出资额、实缴日期和出资方式。
5. 保存查询日期和网页截图；企业信息会变更，不能只保存一个不带日期的链接。

如果系统只显示认缴信息、没有显示实缴信息，应写“当前公开页面未披露实缴”，不要写“实缴为 0”。

## 七、对本项目的暂时判断

目前证据支持的做法是：沧州交通学院在设计学生公司注册流程时，不宜设置“统一必须实缴 X 万元”的未经核实条件。更稳妥的申请表应要求学生如实填写拟定注册资本和实际资金来源，由学校确认场地和校内风险边界，再由沧州属地登记机关核对经营范围、主体类型和登记材料。

注册资本金额、是否先实缴、是否需要银行流水或验资，以及场地协议能否作为经营场所证明，都应列为“学校/登记机关待确认事项”。
