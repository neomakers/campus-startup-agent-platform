# 产品实验

## 定位

真实产品实验是验证商业闭环的低门槛场景，不是项目最终核心的预设答案。产品方向应以能否快速制作、展示、分发、获得反馈并完成交易为主要实验价值。

## 当前候选方向

- 3D 打印；
- 小礼品；
- 个性化签名章、艺术章和文创章等非公章产品；
- 工位摆件与抽象办公用品；
- 情绪价值类小手办；
- DIY 台灯；
- 简单电子硬件；
- 宠物用品；
- 校园猫狗相关产品。

## 要验证的链路

产品设计 → 制作 → 内容拍摄 → 视频分发 → 获取流量 → 客户咨询 → 成交 → 售后 → 数据复盘。

## 边界与风险

公章刻制暂不进入当前业务范围。普通印章类文创产品与公章在用途、宣传、制作和销售上需要保持清晰合规边界，具体规则需在实践前咨询专业人士并验证。

宠物业务先作为项目线，不预设立即成立独立公司。产品安全、知识产权、电子产品责任、平台规则和售后标准均待验证。
