# 沧州交通学院学生个体工商户注册试点

## 这是什么

这是一个面向沧州交通学院在校学生的创业实践注册试点。

当前阶段只负责一件事：

> 在学校管理和登记机关要求允许的前提下，协助学生完成从校内申请、创业园场地确认，到依法办理个体工商户营业执照的流程验证。

本项目不是代办公司，也不是要求学校为学生直接注册企业。学生本人是经营者，依法承担个体工商户经营活动中的责任；学校主要负责校内创业实践审核、场地管理和相关协调，登记机关负责营业执照登记审批。

## 当前拟申请对象

- 学校：沧州交通学院；
- 校区：按学校现有单一校区推进；
- 申请人：在校学生；
- 拟登记形式：个体工商户；
- 拟使用场地：大学生创业园；
- 拟使用区域：实验楼 A 四楼、五楼相关区域；
- 当前业务范围：先以低风险的商务服务、内容运营、文创/办公小物等方向做登记预审，最终以学校和登记机关意见为准。

上述场地、房间号、管理权限和是否允许办理营业执照，尚未视为学校正式确认事项。

## 希望学校协助确认的事项

1. 学生个体工商户创业实践是否可以申请；
2. 学生应向哪个二级学院提交申请；
3. 创新创业教研室是否负责受理和审核；
4. 大学生创业园由学生处管理时，具体由哪个部门确认场地和签署协议；
5. 实验楼 A 四楼、五楼哪些房间可以使用；
6. 学校能否提供场地使用协议、无偿使用证明或租赁协议；
7. 场地文件能否明确允许用于办理个体工商户营业执照；
8. 如登记机关要求，学校由哪个部门协调提供产权/不动产权属材料复印件或管理权说明；
9. 3D 打印、设备使用、材料存放、客户到访等事项是否需要其他部门会签。

## 拟验证的申请链

```text
学生确定经营者和经营内容
  ↓
所在二级学院提出校内申请
  ↓
创新创业教研室受理、审核创业实践事项
  ↓
学生处确认大学生创业园场地和管理权限
  ↓
学校相关部门确认安全、设备和使用边界
  ↓
学校出具场地使用/入驻相关文件
  ↓
向沧州经营场所所在地登记机关预审材料
  ↓
学生本人申请个体工商户设立登记
  ↓
领取营业执照
  ↓
向学校提交营业执照并完成创业园备案
```

这是一条待学校和登记机关确认的工作流程，不是沧州交通学院现行正式制度。

## 学校和登记机关的职责边界

| 环节 | 主要负责方 | 要解决的问题 |
|---|---|---|
| 学生身份、学院意见 | 学生所在二级学院 | 学生是否适合开展创业实践 |
| 创业事项受理 | 创新创业教研室 | 是否接受个体工商户作为创业实践形式 |
| 创业园场地 | 学生处及学校授权部门 | 是否允许使用指定场地，谁有权签署文件 |
| 安全和设备 | 保卫、后勤、实验/实训等相关部门 | 是否涉及用电、设备、材料和人员安全 |
| 营业执照登记 | 沧州经营场所所在地登记机关 | 地址、经营范围和申请材料是否合法合规 |
| 领照后备案 | 学校相关部门 | 营业执照、场地和学生创业实践信息归档 |

学校的入驻或场地证明，不自动等于登记机关认可的经营场所合法使用证明。最终材料必须先向沧州具体登记机关预审。

## 场地材料的基本理解

学生不应自行制作产权证或租赁材料，也不需要取得学校产权证原件。

较稳妥的材料组合是：

- 学校盖章的场地使用协议、无偿使用协议或租赁协议；
- 明确写有允许用于办理个体工商户营业执照的条款；
- 学校或授权管理部门的管理权/权属说明；
- 登记机关要求时，由学校有权部门提供产权证或不动产权属材料复印件；
- 入驻、安全和设备使用等校内管理文件。

河北省公开答复列举了租赁协议与出租方产权材料这一常见组合；国家现行规定要求提交经营场所合法使用证明，但登记机关可以依法通过数据共享等方式核验并简化纸质材料。因此，学校能够提供哪种材料、是否需要产权材料，应以沧州登记机关预审结果为准。[河北省市场监管局场地材料答复](https://scjg.hebei.gov.cn/guestbook/searchOne?guestbookId=3241)；[市场监管总局《个体工商户登记管理规定》](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2025/art_521d2635c33c4a439f638905ed92056c.html)
