# 沧州交通学院学生创业登记办理手册

## 一、这份手册解决什么问题

本手册面向沧州交通学院领导、学生处、创新创业教研室、二级学院和相关管理人员，用于讨论和验证学生创业主体登记的校内办理流程。

当前“注册”分为两条路径：

1. 个体工商户：由一名学生作为经营者，适合个人或小规模试运行；
2. 普通有限责任公司：由一名或多名学生作为股东，适合学生团队、对外签合同和长期代际传承。

本手册不是学校现行制度，也不代表学校已经批准指定场地或同意登记。所有标注“待确认”的内容，需要由学校相关部门或沧州属地登记机关正式确认。

## 二、两种登记形式怎么选择

| 项目 | 个体工商户 | 普通有限责任公司 |
|---|---|---|
| 登记主体 | 学生个人经营 | 一名或多名股东 |
| 适合场景 | 个人试运行、轻资产服务 | 学生团队、长期运营、对外签约 |
| 注册资本 | 不适用公司注册资本制度 | 由股东认缴并写入章程 |
| 实缴问题 | 不适用公司股东实缴制度 | 认缴、实缴、出资期限分别记录 |
| 责任边界 | 经营者承担个体经营责任 | 股东原则上以认缴出资额为限承担责任 |
| 学生毕业交接 | 经营者变更或重新登记 | 依法办理股权转让和资料交接 |

两种形式都需要学校先确认场地和校内管理要求，再由学生或公司向沧州经营场所所在地登记机关提交材料。民办学校不是登记机关，不替学生审批营业执照；但如果使用学校场地，登记机关仍需要核验学校提供的场地使用、授权、权属或其他合法使用证明。

## 三、共同原则和建议办理链

- 学生可以独立发起申请，不以大创立项、竞赛或指导教师为前置条件；
- 二级学院指定统一审核人，主要核实学生身份、学业影响和基本风险；
- 创新创业教研室作为注册事项的直接受理和协调节点；
- 大学生创业园资产按项目团队掌握的信息由学生处管理；
- 拟使用场地：大学生创业园，实验楼 A 四楼、五楼相关区域，具体房间待确认；
- 学校入驻或场地文件不自动等于登记机关认可的经营场所证明。

```text
学生确定登记形式、经营内容和场地需求
  ↓ 学生本人发起申请
  ↓ 二级学院指定统一审核人审核
  ↓ 创新创业教研室受理、补正和转办
  ↓ 学生处确认创业园场地、权限和签约主体
  ↓ 学校有权部门签署场地使用文件
  ↓ 沧州属地登记机关预审
  ↓ 个体工商户或普通有限责任公司正式登记
  ↓ 实名验证、电子签名、补正和领照
  ↓ 回学校备案、入驻和后续管理
```

## 四、每一步对应的文件

| 步骤 | 办理事项 | 对应文件 | 主要部门 | 留存证据 |

| 1.1 | 个体工商户申请 | [个体工商户申请表](docs/templates/student-individual-business-application.md) | 学生本人 | 申请表、日期、附件清单 |
| 1.2 | 普通有限责任公司申请 | [学生公司设立及创业园使用申请表](docs/templates/student-company-application.md) | 学生本人 | 股东、认缴、实缴和资金安排 |
| 2 | 学院统一审核 | [二级学院审核表](docs/templates/college-review-form.md) | 牵头审核学院指定审核人 | 审核结论、签字、盖章 |
| 3 | 教研室受理 | [教研室受理审核表](docs/templates/innovation-office-review-form.md) | 创新创业教研室 | 受理编号、补正、转办记录 |
| 4 | 场地申请 | [校内经营场地申请书](docs/templates/campus-venue-application.md) | 学生处及授权部门 | 房间、期限、场地审批意见 |

| 7 | 学校备案 | 营业执照、协议、承诺和交接材料 | 学生处统一归口 | 备案回执、入驻档案 |

## 五、公司路径必须说明的出资问题

普通有限责任公司申请时，应分别填写：注册资本、每名股东的认缴金额和比例、首期实缴金额、实缴日期和方式、认缴出资期限、资金来源，以及外部资金属于股权投资还是公司借款。

普通有限公司没有统一的法定最低注册资本，但股东认缴出资原则上应在公司成立后五年内缴足。实际缴款应进入公司银行账户，不是交给学校或工商局。[《中华人民共和国公司法》](https://www.npc.gov.cn/npc/c2/c30834/202312/t20231229_433999.html)

“学生团队出资不低于30%”不是全国统一法律要求；如果学校制度采用30%门槛，它首先是入驻条件。是否要求登记前实缴，必须由学校正式制度明确。公司出资、外部投资和借款不得混同，也不得通过公司账户随意退回股东出资。

## 六、学校内部责任边界

- 学生本人：真实填写材料，完成登记并承担经营责任；
- 二级学院：由学校指定一个牵头审核学院；该学院指定统一审核人，代表涉及的其他二级学院完成统一审核，并负责核实学生身份、学业影响、经营内容和基本风险；
- 创新创业教研室：直接受理、编号、补正、协调和形成审核结论；
- 学生处：作为大学生创业园资产、场地和入驻权限的核心协调部门；
- 学生处：统一接收领照后的备案材料，负责入驻档案、后续管理和学生退出交接；
- 其他部门：仅在涉及消防、用电、设备、实验/实训、材料存放、客户到访等事项时协同。

指导教师不作为本登记流程的默认前置条件。学院审核不等于学校对经营结果担保，教研室受理也不等于登记机关已经批准。

### 牵头审核学院规则

学生团队涉及多个二级学院时，不要求多个学院重复审核。学校应在流程开始时指定一个牵头审核学院，并通过书面通知、授权单或流程表明确其主导权和核实权。牵头审核学院可以向其他相关学院核验学生身份、学业影响和必要事项，但由牵头学院统一出具审核结论并承担校内审核流转责任。该规则属于本试点建议，最终以学校正式授权为准。

## 七、线上、线下和场地材料

建议先线下或电话预审，再线上正式提交。学校应先确认实验楼 A 具体房间、使用期限、签约主体和可出具的文件类型，登记机关再核验这些文件能否作为经营场所合法使用证明。

- [河北省政务服务网](https://zwfw.hebei.gov.cn/)：搜索“企业设立登记”或“个体工商户设立登记”；
- [河北省市场监督管理局网上办事平台](http://s.hebamr.cn/bsdt/)：查询登记入口；
- [官方申请与核验入口清单](docs/official-links.md)。

## 八、当前待确认事项

- 学生处是否具有对外签署场地协议的授权；
- 学校是否允许创业园地址登记个体工商户或公司；
- 公司路径是否设置最低注册资本、学生持股比例或最低实缴要求；
- 外部出资方是否可以成为股东或向学生公司提供借款；
- 学生退出、毕业和代际传承时如何办理股权及经营资料交接；
- 具体房间是否满足消防、用电、设备和登记要求。

这些事项必须保留正式回复、窗口记录或盖章文件，不能只凭口头判断。
