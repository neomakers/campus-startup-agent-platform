# 大学生创业实践与 AI Agent 商业运营平台

这是一个以真实公司为实验对象、面向学生创业实践的长期项目。

项目希望打通学生从“学习技术、提出项目想法”到“真正运营一家企业”的全过程：由真人完成必须依赖现实世界的注册、认证、签约、销售和运营动作，由 AI Agent 辅助信息整理、材料准备、流程提醒、状态跟踪、风险提示和运营分析。

项目的核心不是代办注册公司，也不是一开始建设复杂的软件系统，而是持续沉淀一套可复用的 **AI Agent + 真人执行 + 企业真实流程** 基础设施。沉淀形式包括 Agent、API、SOP、流程记录和复盘经验。

第一阶段聚焦于：

1. 建立并长期运营一个商务/创业服务主体；
2. 跑通真实企业注册、认证、支付、云服务和日常运营流程；
3. 将可辅助的环节沉淀为 Agent、API 和 SOP；
4. 以项目实践为来源开发课程；
5. 建立短视频、内容分发、客户管理和销售转化能力；
6. 用 3D 打印等低门槛产品验证从产品到成交的闭环；
7. 形成可以跨届传承的学生创业运营体系。

当前不建设复杂代码框架，不引入数据库、前后端、Docker 或 CI/CD。仓库首先用于记录事实、决策、流程和经验。

## 当前边界

项目暂不追求公司数量多、业务范围大或开放组织规模大。第一阶段优先验证少量核心团队能否把真实流程跑通，并诚实记录结果、限制和失败经验。
