# 沧州交通学院学生个体工商户注册办理手册

## 一、这份手册解决什么问题

本手册面向沧州交通学院领导、学生处、创新创业教研室、二级学院和相关管理人员，用于讨论和验证学生个体工商户注册的校内办理流程。

当前只研究一件事：

> 学生如何从本人发起申请，经学院统一审核、创新创业教研室受理、学生处确认大学生创业园场地，最终向沧州属地登记机关申请个体工商户营业执照。

本手册不是学校现行制度，也不代表学校已经批准指定场地或同意登记。所有标注“待确认”的内容，需要由学校相关部门或登记机关正式确认。

## 二、拟申请对象

- 申请人：沧州交通学院在校学生；
- 登记形式：个体工商户；
- 经营者：学生本人；
- 是否必须有指导教师：本流程建议不作为前置条件；
- 是否必须属于大创项目：不是；
- 是否需要竞赛、答辩或项目立项：不作为本流程默认前置条件；
- 拟使用场地：大学生创业园；
- 拟使用区域：实验楼 A 四楼、五楼相关区域，具体房间待学校确认。

## 三、建议采用的办理链

```text
学生本人准备申请材料
  ↓
学生本人直接发起申请，并提交所在二级学院审核
  ↓
二级学院指定统一审核人完成身份和基本事项审核
  ↓
学生将申请材料和学院审核表提交创新创业教研室
  ↓
创新创业教研室登记受理、补正并作出转办结论
  ↓
学生处确认大学生创业园场地和管理权限
  ↓
学校有权部门与学生签署场地使用/入驻协议
  ↓
学生携学校场地材料到沧州属地登记机关预审
  ↓
线上或线下申请个体工商户设立登记
  ↓
完成实名验证、电子签名和补正
  ↓
领取营业执照并回学校备案
```

## 五、校内部门分工

### 学生本人

学生本人是申请发起人和个体工商户经营者，负责填写材料、配合实名验证、办理登记并承担经营活动中的法律、税务、合同、产品和安全责任。

### 二级学院

二级学院不需要代替学生注册，也不需要把本流程作为大创项目处理。建议由学院指定一名统一审核人，主要确认学生身份、材料完整性、正常学习影响、经营内容和基本风险。学院审核后，将材料报送创新创业教研室。指导教师可以由学生自愿提供，不作为默认前置条件。

### 创新创业教研室

创新创业教研室作为学生注册事项的直接受理和协调节点，负责登记受理编号、材料补正、场地确认转办和最终受理结论。

### 学生处

根据项目团队提供的校内信息，大学生创业园资产划归学生处管理。因此，学生处是创业园场地和入驻权限的核心协调部门。学生处需要确认具体房间、使用期限、签约主体、是否允许用于办理营业执照，以及能否提供场地使用协议、无偿使用证明或其他合法使用证明。

### 其他相关部门

只有在经营内容涉及设备、用电、材料、消防、实验室、客户到访或产品制作时，再根据实际情况协调保卫、后勤、资产、实验/实训等部门。

## 六、线上还是线下办理

建议先线下或电话预审，再线上正式提交。学校先形成协议和场地证明样本，学生携带材料到沧州属地登记机关核验，确认地址和材料可接受后，再通过官方网上平台申请。

线上入口：

- [河北省政务服务网](https://zwfw.hebei.gov.cn/)：搜索“个体工商户登记注册”；
- [河北省市场监督管理局网上办事平台](http://s.hebamr.cn/bsdt/)：查找个体工商户登记或“云窗办照”；
- [官方申请与核验入口清单](docs/official-links.md)。

线下办理：个体工商户登记属于县级事项，实施机关通常为县级市场监管部门或行政审批部门。实验楼 A 所在的具体行政区和对应窗口，应向沧州官方政务渠道确认。[河北省市场监管系统政务服务事项清单](https://scjg.hebei.gov.cn/uploads/1/file/public/202506/20250604153211_oy4seom7f5.pdf)

## 七、场地材料要点

学生不需要取得学校产权证原件，也不能自行制作产权或租赁材料。较稳妥的组合是：学校盖章的场地使用/无偿使用/租赁协议，允许办理营业执照的条款，学校或授权管理部门的管理权/权属说明，以及登记机关要求时提供的产权证或不动产权属材料复印件。

学校入驻证明不自动等于登记机关认可的经营场所合法使用证明。最终以沧州登记机关预审为准。[国家市场监管总局登记规定](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2025/art_521d2635c33c4a439f638905ed92056c.html)；[河北省市场监管局场地答复](https://scjg.hebei.gov.cn/guestbook/searchOne?guestbookId=3241)
